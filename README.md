# SilverScreen-java
# 🎬 SILVER SCREEN – Java-Based Cinema Booking System
## 📌 Features

- 🎥 **Movie Listings**: Interstellar, Avengers, Inception
- 🏙️ **10+ Locations**: Including Greater Noida and Delhi NCR
- 🏛️ **Multiple Theatres** per location
- 🕒 **Showtime Selection** per theatre
- 🪑 **Interactive Seat Layout** with real-time selection
- 💳 **Mock Payment Gateway** simulation
- 🔐 **Dual Portal** System:
  - **User Portal** for booking movies
  - **Controller/Admin Portal** for system management with login access

---

## 🧠 Technologies Used

| Technology       | Purpose                           |
|------------------|-----------------------------------|
| Java             | Core application logic            |
| JDBC / SQL       | Database connectivity & storage   |
| HTML/CSS/JavaScript | UI/UX and frontend interactivity |
| JSP / Servlets   | Server-side rendering & logic     |
| JavaFX * | Desktop-based UI   |
